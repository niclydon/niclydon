I build personal AI infrastructure: a private platform where bounded agents
work over my own data (documents, messages, photos, health, location) instead
of a vendor's cloud memory. By day I direct information security; this account
is the personal work.

Most of the system is private. What is public here falls into two kinds:
maintained open-source projects, and dated snapshot editions of private
systems, published so the architecture can be read without pretending to be a
live mirror. Each snapshot says so on its front page and carries a provenance
note.

## Featured

**[Nexus](https://github.com/niclydon/nexus-public)** — the platform itself.
Bounded AI agents over a personal data and memory lakehouse: Postgres,
a knowledge graph, an MCP tool surface, and a fleet of specialized agent
personas. Public snapshot edition, refreshed October 2026; the private
system has moved well past it, and the repo documents how and why.

**[looki-mcp](https://github.com/niclydon/looki-mcp)** — an MCP server for the
Looki wearable camera, giving AI assistants access to moments, photos,
highlights, and journal entries. Maintained and current.

**[Imprint](https://github.com/niclydon/imprint)** — a public-first identity
and expression profile compiler: human-authored writing and transcripts in,
structured expression profiles out, with the raw corpus never exposed.
Pre-release.

**[Herald](https://github.com/niclydon/herald)** — a DIY desk companion on an
ESP32-S3: RGB light shows, speech, and remote management, built on the Muse
Gadget SDK.

and honest about their date. If a repo here looks quiet, it is probably a
snapshot, not an abandonment.
